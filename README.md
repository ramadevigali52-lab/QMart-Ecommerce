# 🛒 QMart – E-Commerce Website

QMart is a simple and user-friendly e-commerce website developed using **HTML, CSS, and JavaScript**. It allows users to browse products, view product details, and manage their shopping cart.

## ✨ Features

* 🔐 **Login & Registration** – User login and registration pages.
* 🔍 **Product Search** – Search for products easily.
* 🛍️ **Product Details** – View information about selected products.
* 🛒 **Shopping Cart** – View and manage selected products.
* 💾 **Local Storage** – Store selected application data in the browser.

## 💻 Technologies Used

* 🌐 HTML5
* 🎨 CSS3
* ⚡ JavaScript
* 💾 Browser Local Storage

## 📂 Project Structure

* 📁 `Register_login/` – Login and registration pages.
* 📁 `home/` – Home page and product display.
* 📁 `details/` – Product details page.
* 📁 `cart/` – Shopping cart page.

Each folder contains its respective HTML, CSS, and JavaScript files.

## 🔄 How It Works

1. 🔐 Users register or log in.
2. 🔍 They browse and search for products.
3. 🛍️ They select products to view details.
4. 🛒 They manage their selected products in the cart.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required HTML file using the browser or Live Server.
4. Explore the QMart website.

## 🎯 Project Objective

To develop a simple e-commerce website and gain practical experience in frontend development, JavaScript functionality, and web application structure.
